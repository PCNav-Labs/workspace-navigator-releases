# Workspace Navigator releases

Downloads of Workspace Navigator for Windows are published on this repository's [Releases](https://github.com/PCNav-Labs/workspace-navigator-releases/releases) page.

Product information, including how to check a download's SHA-256 before running it, is at [pcnav.net](https://pcnav.net/workspace-navigator/download).

Report problems and suggestions in the [Workspace Navigator feedback repository](https://github.com/PCNav-Labs/workspace-navigator-feedback/issues).
